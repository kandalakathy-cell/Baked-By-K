# Baked-By-K

Part 3 – Baked by K Website

Introduction

For Part 3, I continued developing my home bakery website. I changed the name from Baked by B to Baked by K and updated the website to reflect the new name. I also improved the website by adding JavaScript features and making changes to the CSS. These improvements were made to make the website more interactive, user-friendly and responsive on different screen sizes.

CSS Improvements

I used CSS to maintain the website's design and keep the pages consistent. The website uses pink, white and brown colours, with Georgia as the main font. I used borders, rounded corners, shadows, hover effects and image animations to improve the appearance of the pages. I also added comments to explain different sections of the CSS code, making it easier to understand.

I added a media query to improve the website's layout on mobile phones and tablets. This adjusts the text, navigation links, images and forms to fit smaller screens better.

JavaScript Features

I added JavaScript features to make the website more interactive. A welcome message appears when visitors open the home page. The order form checks that customers enter a 10-digit phone number and do not select an event date in the past. I also added an order preparation reminder that suggests placing an order between five and seven days before the selected event date.

The product search allows visitors to search for products, while the weekly offers feature allows them to show or hide the offers. The contact form checks the phone number entered and prepares an email containing the customer's details. The email opens in the visitor's email application for them to review and send.

Google Maps

I added a Google Maps embed to the contact page to show the general Johannesburg area. This gives visitors an idea of the area where the bakery hopes to operate in the future.

Testing

I tested the website in the browser to check that the pages opened correctly and the JavaScript features worked. I checked the welcome message, order form validation, order preparation reminder, product search, weekly offers and contact form. I also used the mobile preview to check that the website layout fitted smaller screens.

Conclusion

The changes made in Part 3 improved the appearance and functionality of Baked by K. Changing the bakery's name, improving the CSS and adding JavaScript features helped make the website more interactive and easier to use. Testing also helped me check that the main features worked as expected.
